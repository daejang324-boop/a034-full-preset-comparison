정상 완료한 GPU 작업의 시간 배치

가로축은 첫 정상 GPU 작업 시작 후 경과시간입니다. 로컬 제어기의 작업 명령 시작·종료 시각을 사용했습니다. 실패한 작업에서 진행한 부분 계산은 이 그래프에 포함하지 않습니다. 동시 임대는 생성 확인~삭제 요청 구간으로 집계했습니다.

“서버 4대를 썼으니 제작도 4배 빨라졌다”는 결론은 낼 수 없습니다.

초기 4편 중 첫 임대로 끝난 것은 a038 한 편이었습니다. 나머지는 전송 지연·초기 처리 정체 등으로 복구했고, 성공한 처리 구간은 순차적으로 배치됐습니다. 이 4건만으로 일반적인 실패 확률도 추정하지 않습니다.

이번 4편 · 이 컴퓨터의 실제 사용량

a035는 최종 조립을 로컬에서 처리했습니다.

복구와 로컬 최종 조립을 측정한 구간의 CPU 누적은 772.28초, 최대 RSS는 2,451.3 MiB였습니다. 앞선 중단 실행의 CPU 누적이 불완전하므로 이를 전체 사용량이라고 표시하지 않았습니다.

공통 기획·이미지·음성 준비, 최종 QA, NAS 복사, 웹과 다른 앱은 제외됩니다. 전력·발열·팬 소음·Mac 전체 절감률은 미측정입니다. CPU 누적시간은 경과시간과 다르며, RSS는 프로세스 메모리입니다.
